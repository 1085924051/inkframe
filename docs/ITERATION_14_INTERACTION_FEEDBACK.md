# Iteration 14 — 前端交互反馈

## 目标

修复部分按钮点击后反馈不明显的问题，让工作台和后台配置页的操作拥有一致的 hover、按下、焦点和禁用状态反馈。

## 已完成

- 模板下载、模板导入和 Provider 检查按钮纳入统一过渡样式。
- 补充模板按钮 hover 背景、阴影和轻微位移动画。
- 补充样式卡片按下反馈。
- 保留现有主按钮、幽灵按钮和异步按钮的禁用/旋转反馈。
- 增加 `prefers-reduced-motion` 支持，用户关闭动态效果时不强制播放过渡动画。
