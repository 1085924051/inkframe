# InkFrame Studio 商业化落地迭代方案（总架构师）

## 1. 模型 API 配置系统
- **存储**：`SystemSetting` 键值表：`key`(唯一)、`value`、`isSecret`、`group`、`updatedBy`、`updatedAt`。
- **配置项**：文本模型（OpenAI 兼容：接口地址 / API Key / 模型名 / 温度）、PenShot 分镜、视频（Runway / 可灵 / Seedance）。
- **加密/脱敏**：密钥字段用 AES-256-GCM 加密落库（主钥 `SETTINGS_ENCRYPTION_KEY`），管理 API 只返回脱敏值（前4后4，中间 `••••`）。
- **解析顺序**：DB 配置 > 环境变量兜底 > 本地 mock 回退，统一经 `resolveModelConfig()` 读取。
- **缓存与失效**：进程内缓存 + 30s TTL，写操作后主动失效。

## 2. 后台管理改进（按优先级）
- P0：① 模型配置设置页（CRUD + 连通性测试）② 仪表盘统计（用户/项目/任务/调用量）
- P1：③ 用户管理增强（禁用、角色变更、重置密码）④ 操作审计日志
- P2：⑤ 任务重试/队列管理 ⑥ 数据导出报表

## 3. 前端可用性（按优先级）
- P0：全局 Loading/Error 边界、路由加载态、空态、表单校验反馈
- P1：响应式移动端适配、导航面包屑、统一 Toast
- P2：无障碍（键盘/ARIA）、暗色模式、骨架屏

## 4. 商业化差距清单
- P0：Docker 化部署、HTTPS、密钥与加密主钥隔离、SQLite 定期备份、结构化日志
- P1：监控（健康检查）、接口限流、CSRF/鉴权加固、权限自动化测试
- P2：单测 + E2E 覆盖率 ≥70%、数据库迁移脚本化、灰度发布

## 5. 三 Agent 职责与协作闭环
- **总架构师**：定方案与接口契约、评审代码与测试、仲裁争议、把关上线。
- **开发 agent**：按契约实现、修复缺陷、维护文档。
- **测试 agent**：依据契约编写测试用例、执行回归、输出缺陷报告。
- **闭环**：契约先行 → 开发实现 → 测试验证 → 缺陷报告（标题/复现步骤/严重级/期望结果）→ 开发修复 → 回归通过 → 架构师验收。
