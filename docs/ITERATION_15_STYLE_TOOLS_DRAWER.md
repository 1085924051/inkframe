# Iteration 15 — 风格工具侧滑窗

## 目标

解决作家卡/导演卡模板、导入和分享操作区固定在右下角并遮挡工作台内容的问题。

## 已完成

- 右下角改为“风格工具”入口按钮。
- 点击后从右侧展开工具抽屉。
- 抽屉包含作家卡模板、导演卡模板、导入和分享操作。
- 支持关闭按钮、点击遮罩和 `Escape` 键关闭。
- 侧滑窗在移动端按视口宽度自适应，不遮挡主内容操作区。
- 保留原有导入、下载和分享逻辑。

## 验证

- TypeScript：`npx.cmd tsc --noEmit` 通过。
- Vitest：43 项测试通过。
- 生产构建：`npm.cmd run build` 通过。
