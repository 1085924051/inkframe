# Inkframe Studio 网站现状

更新时间：2026-09-24

## 当前定位

Inkframe Studio 已形成「作家风格 → 风格化剧本 → 分集/场景 → 分镜提示词 → 异步视频任务 → 素材库 → 成片任务」的可运行工作台。文本生成、分镜生成、视频 Provider 和成片任务之间保持可替换边界。

## 已可用能力

- 作家风格卡、导演风格卡选择、导入、分享，以及文本样本蒸馏。
- 剧本长度、叙事视角、单集字数、集数和 Story Bible 配置。
- 生成结果持久化，重新打开项目时回填生成参数。
- 多集项目：分集状态、按集生成、按集读取剧本/场景/分镜。
- 分镜卡显示具体标题，不再显示统一模板；标题、镜头参数、图片/视频/负面提示词可编辑并保存。
- 单镜头重拍只更新当前 Shot，不复制项目；原项目、其他镜头和其他素材关系保持不变。
- Runway、可灵、Seedance、Mock Provider 的可插拔接口。
- 视频任务异步提交、状态轮询、失败重试和同镜头任务幂等。
- 素材按项目、分集、镜头校验归属，可导入 URL，支持图片/视频/音频预览。
- 成片合成改为 RenderJob 异步任务，支持按集合成和状态轮询。
- 模型配置页支持文本模型真实连通测试，以及 Runway、可灵、Seedance 的独立配置/地址检查；模型字段会提示是否可选及默认值。
- SQLite 本地开发，Prisma 数据模型已为 Postgres 迁移保留结构化边界。

## 当前验证证据

- `42` 项 Vitest 单元/集成测试通过。
- `npx tsc --noEmit` 通过。
- `npm run build` 通过。
- 开发服务：`http://localhost:3001`，HTTP 200。

## 已知限制

- 当前浏览器连接器缺少授权令牌，尚未完成真实浏览器点击和截图验收。
- 本地默认生成管线是确定性演示实现；配置远程文本模型后才使用真实 LLM。
- Runway、可灵、Seedance 的具体请求字段仍需按用户实际账号和官方版本联调。
- 素材导入当前以 URL 为主，尚未接入对象存储和本地文件上传。
- 成片任务已异步化，但仍需要部署 Redis/Worker 才能获得生产级跨进程可靠性；无 Redis 时使用进程内 worker 兜底。
