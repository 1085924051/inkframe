# Iteration 13 — 模块化导入模板

## 目标

补齐工作台中创作简报、分镜提示词和素材导入三个模块的模板下载与导入能力，降低长篇多集项目的重复录入成本。

## 已完成

- 新增 `project-brief.template.json`：主题、剧本长度、叙事视角、项目形态、集数、单集字数和 Story Bible。
- 新增 `shot-prompt.template.json`：标题、时长、景别、机位、运镜、图片提示词、视频提示词和负面提示词。
- 新增 `asset-import.template.json`：素材名称、类型和 URL。
- 导入创作简报会回填表单，不会自动发起生成。
- 导入分镜模板只更新当前分镜草稿，必须点击“保存分镜修改”才会持久化。
- 导入素材模板只回填素材表单，必须点击“导入素材”才会创建素材记录。
- 保留现有作家卡、导演卡和模型配置模板能力。

## 验证

- TypeScript：`npx.cmd tsc --noEmit` 通过。
- 生产构建：`npm.cmd run build` 通过。
