# InkFrame Studio 设计规范

本文档描述 InkFrame Studio 的统一 UI 设计系统。所有页面与项目视图均遵循同一套令牌与组件约定，保证不同项目（不同「作家 × 导演」组合）之间视觉风格一致。

## 1. 设计令牌

定义于 `app/globals.css` 的 `:root`，全局唯一来源，组件不写死颜色值。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#1b2221` | 主文字色 |
| `--muted` | `#75807b` | 次级文字 |
| `--line` | `#d9ded9` | 描边 / 分隔线 |
| `--paper` | `#f5f7f3` | 页面底色 |
| `--card` | `#fbfcf9` | 卡片底色 |
| `--accent` | `#d65e3b` | 强调色（进度、编号、LOGLINE 左条） |
| `--teal` | `#257b70` | 品牌色 / 主操作色 |

**字体**

| 用途 | 字体 |
| --- | --- |
| 正文 / 交互 | `Manrope` |
| 中文标题 / 剧本 | `Noto Serif SC`（衬线，体现「文字→镜头」气质） |
| 数据 / 标签 / 编号 | `DM Mono`（等宽，用于 SCRIPT、轴值、徽标） |

## 2. 组件约定

- **侧栏 `.sidebar`**：品牌、导航、项目列表统一在 `#edf1eb` 底 + 右侧 `1px` 分隔线；当前项高亮为 `#dde8df` + `--teal`。
- **面板 `.panel`**：统一圆角 `13px`、细描边 + 轻投影；标题区 `.panel-heading` 底部 `1px` 分隔。
- **主按钮 `.primary-button`**：品牌色填充；辅助按钮 `.ghost-button` / `.text-button` 统一描边与字色。
- **状态徽标 `.status-badge`**：五种状态使用同一形状、不同语义色（`draft` 灰 / `queued` 金 / `processing` 蓝 / `complete` 绿 / `failed` 红）。
- **流水线 `trace` 与步骤 `.workflow`**：以 `01–04` 编号 + 等宽字体贯穿四个阶段，进度语义一致。

## 3. 跨项目统一原则

1. **同一套令牌**：所有项目视图共享 `:root` 变量，不随项目内容改变框架颜色。
2. **同一套组件**：项目详情（剧本 / 场景 / 分镜 / 状态）始终复用 `.panel`、`.shot-card`、`.scene-item`、`.status-badge` 等组件。
3. **风格卡仅作内容**：导演视觉卡的 `palette` 只用于卡片内的色条展示，不改变全局界面配色；切换「作家 × 导演」组合只替换文本内容，不替换布局与交互语言。
4. **响应式一致**：`900px / 620px` 两档断点对侧栏、卡片栅格、面板统一降级。

## 4. 新增 UI 的最小规范

- 颜色一律引用令牌，禁止新增硬编码色值（确需新增语义色时先登记到 `:root`）。
- 交互元素使用既有 `button` 样式类；新状态必须复用 `.status-*` 的语义色体系。
- 中文标题用 `Noto Serif SC`，数据/编号用 `DM Mono`，保持三套字体的既有分工。
